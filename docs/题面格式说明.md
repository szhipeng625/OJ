# 题面 Markdown 格式说明

题面描述使用 **Markdown** 编写：服务端「题目工作台 → 题面」页编辑，客户端用 Markdig（`UseAdvancedExtensions()`）渲染成网页展示（题库页、比赛页、做题页）。

---

## 一、基本格式

| 功能 | 写法 | 效果 |
|---|---|---|
| 一级标题 | `# 标题` | 大标题 |
| 二级标题 | `## 标题` | 中标题 |
| 三级标题 | `### 标题` | 小标题 |
| 加粗 | `**文字**` | **文字** |
| 斜体 | `*文字*` | *文字* |
| 行内代码 | `` `code` `` | `code` |
| 删除线 | `~~文字~~` | ~~文字~~ |
| 分隔线 | `---` | 一条横线 |

## 二、列表

```markdown
- 无序项一
- 无序项二
  - 嵌套子项

1. 有序项一
2. 有序项二
```

## 三、引用

```markdown
> 这是引用内容
```

## 四、代码块

用三个反引号围起来（```），首行可写语言名：

````markdown
```cpp
#include <iostream>
using namespace std;
int main() {
    return 0;
}
```
````

## 五、链接与表格

```markdown
[链接文字](https://example.com)

| 列1 | 列2 |
|-----|-----|
| 值1 | 值2 |
```

## 六、题目推荐结构

```markdown
## 题目描述
……（正文，支持上面的所有格式）

## 输入格式
……

## 输出格式
……

## 数据范围
……
```

## 七、样例（不用手写）

样例**不要写进描述里**。在服务端「生成标准答案」页，给要作为样例的数据组勾上「样例」，上传数据库后，客户端会在题面下方自动生成：

- **样例：xxx**（输入 + 输出两个代码块）

## 八、服务端编辑器快捷按钮

题面编辑框上方的工具栏按钮对应的 Markdown：

| 按钮 | Markdown | 说明 |
|---|---|---|
| **B** | `**文字**` | 加粗 |
| **I** | `*文字*` | 斜体 |
| **H** | `# ` | 标题 |
| **• 列表** | `- ` | 无序列表 |
| **❝ 引用** | `> ` | 引用 |
| **代码块** | ` ``` ` | 代码块 |
| **分隔线** | `---` | 分隔线 |

用法：先选中文字再点按钮，或把光标放到目标行点按钮。

---

## 说明

- 存储：`problems/{题号}/statement.txt`，第一行为标题，其余为描述（Markdown）。
- 渲染：客户端 `MarkdownRenderer`（Markdig）转 HTML 后在 WebBrowser 中展示。
