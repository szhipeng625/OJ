ACMDOG

在线判题系统 · Online Judge

专业级 C++ 在线判题平台，服务算法竞赛与程序设计训练全场景。

简介

ACMDOG 是一套专业级在线判题（Online Judge）平台，覆盖「命题 · 发布 · 判题 · 竞赛」全流程，以高性能 C++ 判题引擎为核心，当前支持 C++ 语言评测，选手端与出题端协同、云端多端实时同步、开箱即用。

题库特色

ACM / ICPC 竞赛算法 CPU 底层算法 数据结构与算法 体系结构与内核算法 经典算法专题

核心优势

四大能力，构筑安全、可靠、高效的竞赛与训练体验。

🛡️

安全性

端到端安全，全链路护航。

  • HTTPS 加密传输，数据全程防窃取、防篡改
  • 中间件统一权限验证，拦截越权与恶意提交
  • 判题进程沙箱隔离，编译运行受时间与资源双重约束
🤝

共享性

云端一体，多端协同、即开即用。

  • MySQL + 远端 LSM 双存储，题库与提交数据云端统一托管
  • 选手端与出题端共享判题核心与云端接口
  • 题目一键发布，全员即时共享最新题库
⚡

并发性

高性能引擎，从容应对高并发。

  • C++ 判题引擎，毫秒级响应、逐测试点精准判定
  • 中间件网关缓冲转发，支撑大量用户同时提交
  • 榜单实时更新、多端同步，比赛并发不卡顿
🧬

数据生成器

丰富生成器库，一键产测大数据。

  • 内含丰富大量的数据生成器模板，快速构造各类测试数据
  • 全局生成器库统一管理，一处配置多处复用
  • 可视化生成高强度测试数据，轻松构造特殊样例

下载

下载安装器（点击这里）

下载 oj.exe 后双击运行即可完成安装（客户端 + 出题端）。

安装说明

  1. 运行 oj.exe，一键安装客户端与服务端。
  2. 桌面 / 开始菜单会生成「ACMDOG客户端」「ACMDOG服务端」「卸载 ACMDOG」快捷方式。
  3. 卸载时点击「卸载 ACMDOG」即可一键清理。
  4. 运行前需安装 .NET 8 桌面运行时。
