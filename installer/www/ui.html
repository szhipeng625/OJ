客户端 · ACMDOG

登录、刷题、本地调试、比赛
登录界面
输入用户名与密码登录，登录后自动恢复上次会话。
题库主页 · 个人信息
左侧题目列表（可搜索、显示通过状态），右侧个人资料与通过进度统计。
题目详情
单击题目即可查看完整题面：描述、输入输出格式、样例与标签。
做题窗口
左侧题面、右侧代码编辑器（含补全提示），支持本地调试与提交判题。
比赛列表
查看已发布比赛、报名状态与比赛时间，可报名正式或打星参赛。
比赛题目
进入比赛后按题号查看本场题目，顶部可切换比赛首页 / 排行榜 / 提交记录。
比赛提交记录
本场全部提交按时间倒序展示，双击可查看提交代码。

出题端 · ACMDOG 出题工作台

命题、数据生成、标程、发布、比赛管理
登录界面
仅 admin / author 角色可登录出题端。
工作台
题库列表（双击打开题目编辑窗口，可多窗口并行编译/评测），支持新建题目与比赛管理。
题目编辑
编辑标题、时限、内存、标签，题面支持 Markdown 富文本。
数据生成器
勾选绑定生成器并一键生成测试数据，可逐组预览 .in 输入。
生成标准答案
编译标程并批量跑出 .out 答案，支持输入/输出逐组对比。
发布题目
一键校验题目完整性（题面/标程/生成器）并发布，客户端可见。
比赛管理
新建 / 编辑比赛，设置起止时间并勾选本场题目，保存即发布。
